# COVID-19 Data Analysis

A SQL-based data analysis project focused on exploring COVID-19 datasets to extract meaningful insights using analytical SQL queries.

The project demonstrates practical data analysis techniques including aggregations, joins, Common Table Expressions (CTEs), window functions, and data exploration on real-world COVID-19 data.

---

## Features

- Import COVID-19 datasets into SQL
- Explore and analyze pandemic data
- Perform analytical SQL queries
- Generate statistical insights
# COVID-19 Global Data Analysis

A complete end-to-end Data Analytics project exploring the global impact of COVID-19 using the **Our World in Data (OWID)** dataset.

This project demonstrates a complete analytics workflow including SQL, Python, statistical analysis, and business intelligence to support data-driven public health decision making.

---

## Project Goal

Analyze global COVID-19 data to answer real-world business questions related to pandemic trends, vaccination effectiveness, healthcare performance, and future pandemic preparedness.
